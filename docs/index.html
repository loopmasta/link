Link

Push-to-talk for ham radio, for iPhone.

Link joins amateur radio networks that run SvxReflector, such as FM-Funknetz, as a node on your iPhone: you hear the talkgroups you choose and talk with one button, and you see which stations are active.

Link needs a node callsign and an authentication key, which the operators of your network issue to licensed radio amateurs. Transmitting requires an amateur radio licence and must follow the rules that apply to you.
